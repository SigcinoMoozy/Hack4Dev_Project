# Hack4Dev-Project

## Project structure

- `data/raw/` - original, untouched data
- `data/processed/` - cleaned data
- `notebooks/` - exploration and model development
- `src/` - preprocessing, model, evaluation code
- `app/` - application code
- `presentation/` - slides and demo material

## Setup

```bash
git clone <repo-url>
cd Hack4Dev-Project
python -m venv venv
source venv/bin/activate   # Windows: venv\Scripts\activate
pip install -r requirements.txt
```
